# Success Metrics
## Personal Finance AI Assistant

### Model Quality Metrics
| Metric | Definition | Target |
|--------|-----------|--------|
| Task Completion Rate | % of questions answered correctly | > 85% |
| Hallucination Rate | % of responses with invented figures | < 5% |
| Anomaly Precision | % of flagged transactions genuinely unusual | > 80% |
| Response Relevance | % of answers referencing actual user data | > 90% |

### Product Metrics
| Metric | Definition | Target |
|--------|-----------|--------|
| Bank Connection Rate | % of users completing OAuth flow | > 90% |
| D7 Retention | % of users returning after 7 days | > 40% |
| Session Length | Average questions asked per session | > 3 |
| Savings Action Rate | % taking a suggested saving action | > 20% |

### How We Measure
- Task completion: manual review of 100 test queries
- Hallucination: compare AI output against actual CSV data
- Savings action: follow-up survey after 30 days

### What Good Looks Like
A user connects their bank, asks 3-5 questions, 
identifies one area to cut back, and returns the 
following month to check progress.
